# Largus Garage

Личный PWA-бортовой журнал для Lada Largus.

## Автомобиль
- Lada Largus, 2018
- ВАЗ-21129, 1.6 16V, 106 л.с.
- МКПП, бензин
- Начальный пробег: 241 060 км

## Возможности
- Текущий пробег и журнал обслуживания
- Замены масла, фильтров и расходников
- Расчёт следующей даты/пробега по введённому интервалу
- Каталог деталей, брендов и артикулов
- Расходы и резервное копирование JSON
- Локальная работа после первого открытия

## Публикация
GitHub Pages: Settings → Pages → Deploy from a branch → Branch: main → Folder: /(root) → Save.

После публикации открыть адрес Pages в Safari и выбрать Поделиться → На экран Домой.

## Хранение данных
История ТО, каталог деталей и настройки хранятся локально в браузере устройства. Репозиторий содержит только исходники и изображения. Для переноса/защиты данных используйте экспорт JSON в приложении.

> Значения интервалов по умолчанию являются редактируемыми ориентирами, а не подтверждённым заводским регламентом. Уточняйте обслуживание по руководству и условиям эксплуатации.
