# Largus Garage

Личный PWA-бортовой журнал для Lada Largus.

## Автомобиль
- Lada Largus, 2018
- ВАЗ-21129, 1.6 16V, 106 л.с.
- МКПП, бензин
- Начальный пробег: 241 060 км

## Возможности
- Журнал обслуживания, даты, пробеги и расходы
- Каталог деталей, брендов и артикулов
- Оценка пробега по GPS с фильтрацией координат точностью хуже 100 м
- Подтверждение пользователем перед прибавлением GPS-поездки к одометру
- Экспорт и импорт JSON-резервной копии
- Локальная работа после первой загрузки

## GPS на iPhone
GPS-трекинг в PWA рассчитан на работу в активном открытом приложении. При сворачивании или блокировке экрана запись ставится на паузу: веб-приложение не имеет гарантированного фонового доступа к геолокации на iOS. Для надёжной фоновой записи потребуется отдельная нативная оболочка iOS с разрешениями и фоновым режимом Core Location.

## Публикация
GitHub Pages: Settings → Pages → Deploy from a branch → Branch: main → Folder: /(root).

На iPhone откройте опубликованный адрес в Safari → Поделиться → На экран Домой.

## Хранение данных
История обслуживания, поездок и каталог деталей хранятся локально на устройстве. Репозиторий содержит только код и общедоступные изображения. Для переноса/защиты данных используйте экспорт JSON.

> GPS-расстояние приблизительное: зависит от качества сигнала и условий приёма. Приложение отбрасывает точки с accuracy более 100 м и фильтрует мелкие скачки координат. Интервалы обслуживания — настраиваемые пользователем ориентиры, не заводские предписания.
